# Joint Exclusivity

**Paper:** Joint Exclusivity  
**Year:** 2024 (exact year and authors are stated on the paper's title page)

Replication of the main theoretical constructions and numerical experiments from the paper on *jointly exclusive* (JE) random vectors.  A non-negative random vector is JE when no event occurs on which all components are simultaneously positive.  The paper characterises when such vectors exist, provides an explicit wrap-around construction that is extremal in convex order, and develops a canonical and a generalised family parameterised by face copulas and distortion functions.

---

## Experiments

| Script | Paper section | What it reproduces |
|--------|---------------|--------------------|
| `exp/exp1.py` | Section 3.1 | Existence condition, wrap-around construction, marginal preservation, JE property, claim-count support, convex-order minimality |
| `exp/exp2.py` | Section 3.2, Example 3.9 | Canonical JE family, face-by-face CDF, trivariate correlations as a function of λ |
| `exp/exp3.py` | Section 3.3, Example 3.13 | Generalised JE with linear-truncation distortion, capacity G\*, face-severity confinement |
| `exp/exp4.py` | Section 3.4, Section 4.1 | m-exclusivity hierarchy, wrap-around attains strongest level, convex-order bounds, threshold-exceedance JE |
| `exp/exp5.py` | Section 4.2, Example 4.8 | Aggregate-loss extremal structures, stop-loss premiums, TVaR; 10-line benchmark table |

## Running experiments

Run from the repository root:

```bash
python -m exp.exp1   # wrap-around construction (Section 3.1)
python -m exp.exp2   # canonical JE, Example 3.9 (Section 3.2)
python -m exp.exp3   # generalised JE, Example 3.13 (Section 3.3)
python -m exp.exp4   # m-exclusivity hierarchy (Sections 3.4, 4.1)
python -m exp.exp5   # aggregate loss, Example 4.8 (Section 4.2)
```

Or run everything in sequence:

```bash
bash reproduce.sh
```

Each run overwrites the JSON and PNG files in `results/`.  After a rerun the numbers and verdicts in `results/RESULTS.md` must be checked against the new files and updated by hand.
